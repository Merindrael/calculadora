🧮 Calculadora Simples em Java

Este é um projeto simples de uma calculadora em console desenvolvida em Java, criada para realizar operações matemáticas básicas de forma interativa utilizando a estrutura de repetição do-while e a seleção de caminhos com switch-case.
Desenvolvido por Rodrigo Silva.

🚀 Funcionalidades

O aplicativo permite ao usuário escolher entre as seguintes opções no menu:
Somar ()
Subtrair ()
Multiplicar ()
Dividir () (inclui tratamento para divisão por zero e exibição do resto da divisão).
Sair do programa.

🛠️ Tecnologias Utilizadas
Java (JDK 8 ou superior)
Classe java.util.Scanner para captura de entrada via terminal.

📋 Pré-requisitos

Para executar este projeto em sua máquina, você precisa ter instalado:
JDK (Java Development Kit) instalado.
Um ambiente de desenvolvimento integrado (IDE) como IntelliJ IDEA, Eclipse, VS Code, ou o próprio terminal do sistema operacional.

⚙️ Como Executar

Clone este repositório ou copie o código fonte para um arquivo chamado Main.java.
Abra o terminal na pasta onde o arquivo está salvo.

Compile o código com o comando:
javac Main.java


Execute a aplicação com o comando:
java Main


💡 Exemplo de Uso
Digite o primeiro valor: 
10
Digite o segundo valor: 
3

Escolha a operação:
1. Somar 
2. Subtrair 
3. Multiplicar 
4. Dividir 
5. Sair 
Opção: 
4
Resultado de 10 / 3 é igual a 3.333333 (resto: 1)
